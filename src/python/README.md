# Python Source Code

This folder contains the Python source code for the Bachelor thesis project.

## Structure

- `radargram.py`: Contains the `Radargram` class for feature calculation.
- `feature_plotting.ipynb`: Jupyter notebook for feature plotting and postprocessing.
There are three subfolders containing feature plots, each corresponding to a different preprocessing step:
1. `feature_plots_raw/`: Step 1 – plots of raw features.
2. `feature_plots/`: Step 2 – plots after standard preprocessing.
3. `feature_plots_khigh/`: Step 3 – plots after advanced processing (e.g., k-high filtering).
- `SelfOrgMap/`: Implementation of the Self-Organizing Map.
