# Data Folder README

This folder contains three subfolders representing different preprocessing steps of the Radargramm dataset:

- **raw/**: Step 1 — Contains the original, unprocessed data.
- **processed/**: Step 2 — Contains data after initial preprocessing.
- **external/**: Step 3 — Contains data after further processing.

Each subfolder includes `.mat` files:
- Main Radargramm data
- `x.mat`: X coordinates
- `t.mat`: T coordinates

Use these files according to the required preprocessing stage for your analysis.
